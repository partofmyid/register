# Registering w/ The Web UI

This document shows you a step-by-step, partially visual guide on registering a subdomain with the help of the Web UI (this website!)

We'd assume you already have:
- A GitHub account
- [Forked](https://github.com/partofmyid/register/fork) the repository
- A functional and live website hosted on one of the [supported services](/docs/services)

## Searching for your subdomain

[Click here](https://part-of.my.id/query) to go to the search page. Type in your desired subdomain and click "Search". If your subdomain is available, you will see a green checkmark and a "Register" button. Click on it to proceed.
